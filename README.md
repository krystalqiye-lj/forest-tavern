# 林间拾叶

把喜欢的角色种成花草，沿着木牌走过大树、小溪、静湖和瀑布。点一株花，就能在毛边书页上打开那个人的故事。图鉴、天气、环境音和阅读字体都可以在主题里调整。

## 安装

在 **SillyTavern → 扩展程序 → 安装扩展程序**，粘贴下面的链接，安装后刷新酒馆即可。首次安装且只有这套主题时，刷新后就会进入森林。

```text
https://github.com/krystalqiye-lj/forest-tavern
```

使用 SillyTavern 1.19.0 验证，主题本身无需酒馆助手。电脑和手机浏览器访问同一个酒馆时，服务端装一次即可。安卓 Termux 本机运行酒馆时，在手机自己的酒馆里完成相同操作。其他酒馆客户端的兼容性取决于它对 SillyTavern 扩展的支持。

已安装的用户可通过 **木牌 → 扩展 → 管理扩展 → 林间拾叶 → 更新** 升级，随后刷新页面。安卓 Termux 和电脑各自运行酒馆时，需要在各自的扩展管理里更新。原来种下的植物和已解锁品种会保留。

## 1.4.2 更新

- 设置面板的滚动内容留在书页边缘以内，标题栏和关闭按钮固定在顶部。
- 加深提示词关闭状态、设置控件和背景缩略图文字的颜色对比。窄屏下提示词操作按钮可换行显示全名，Token 列与操作图标分开排列。

## 使用

- **图鉴**可以按角色打开对话、挑选植物、种花和移栽。
- **天气**里能切换天气和环境音，打开「环境音」后播放。手机在场景上左右滑动看风景，点花草一次靠近并看角色名，再点花或名字进入对话。点「移栽」后，再点场景里的位置即可放下。
- **木牌 → 扩展 → 管理扩展**可以更新或停用。合上书会回到森林。
- 如果也装了星间，打开 **图鉴 → 图鉴封底 → 前往星间**。切换后酒馆会刷新，并在当前浏览器记住所选主题。只有一个主题时直接使用即可。[星间 · 私人观景舱](https://github.com/krystalqiye-lj/xingjian-cabin)
